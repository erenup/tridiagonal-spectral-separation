# KE-02 exact checks: the checkers and their negative controls.
# A negative control is a deliberately wrong constant, formula or input that must be rejected;
# a checker (and run_checks.py) fails if any control is accepted. run_checks.py requires that the
# controls listed here are exactly the controls executed and rejected, with identical descriptions.
# Layout: checker file name; indented two spaces: check family; indented four spaces: control id,
# two spaces, description.
